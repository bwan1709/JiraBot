# Project Guidelines & Context
- **User Background**: The user is an engineer at ACORNERI.
- **Coding Standards**: 
  - Strict focus on security.
  - Maintain a strict and well-organized directory structure.
  - Every single line of code must have a clear meaning and purpose (no boilerplate without understanding, no dead code).
- **Project Roadmap**: The ultimate goal of this project (JiraBot) is to build a comprehensive HR (Human Resources) management system.
  - It will integrate with Jira for task and time management.
  - HR personnel will be able to log in to interact with the system, review and approve reports, etc.
